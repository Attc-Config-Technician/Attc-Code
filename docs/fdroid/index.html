F-Droid

Install Attc Code from F-Droid.

Add the signed Attc Code repository to the F-Droid client once. After that, Attc Code installs and updates like any other F-Droid app.

1. Add the repository

Open this page on the phone where F-Droid is installed, then tap the button below. If your F-Droid client does not open the link, add the HTTPS address manually under Settings → Repositories → Add repository.

Open in F-Droid
https://attc-config-technician.github.io/Attc-Code/fdroid/repo

Or scan this code with the F-Droid repository scanner:

2. Install Attc Code

  1. Let F-Droid refresh the new repository.
  2. Search for Attc Code in F-Droid.
  3. Open the listing and tap Install. F-Droid verifies the APK signature against the release key.

Updates are delivered through F-Droid. The app signing key does not change, so your Ubuntu environment and sessions are preserved.
