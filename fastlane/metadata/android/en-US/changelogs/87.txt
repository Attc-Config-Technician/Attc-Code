Claude Code, Kimi Code and Antigravity now install themselves with their official installers when they are missing, so a fresh Ubuntu environment no longer stops at command not found. App updates repair the existing Ubuntu environment instead of replacing it, so installed tools and files stay in place. Claude Code setup also works when python3 is not available. Full-screen TUIs now render correctly after scrolling, so menus no longer show duplicated or overwritten lines.
